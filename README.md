📌 Жоба туралы

QazaqLoc QA — компьютерлік және мобильді ойындардағы қазақша аудармалардың сапасын тексеруге арналған бағдарламалық құрал.

Жобаның мақсаты — ойын мәтіндеріндегі аударма қателерін анықтау, терминдердің бірізділігін сақтау және мәтіндерді контекстке сай табиғи қазақ тіліне бейімдеуге көмектесу.

🎯 Негізгі міндеттері

- JSON және ARB форматындағы файлдарды оқу.
- Бос аудармаларды анықтау.
- Ұзын мәтіндерді белгілеу.
- Аударылмай қалған ағылшын сөздерін табу.
- Терминдерді сөздікпен салыстыру.
- Қателер туралы есеп қалыптастыру.
- Қазақша аударманың дұрыс нұсқасын ұсыну.

⚙️ Қолданылатын технологиялар

Технология| Қолданылуы
Python| Тексеру логикасы
JSON / ARB| Ойын мәтіндерін сақтау
CSV| Терминдер сөздігі
HTML| Нәтижелерді браузерде көрсету
AI API| Болашақта контекстік аударма ұсыну

🔄 Бағдарламаның жұмыс істеу кезеңдері

1. ARB немесе JSON файлын жүктеу.
2. Мәтіндерді автоматты тексеру.
3. Қателерді анықтау.
4. Түзету ұсыныстарын қалыптастыру.
5. Маманның ұсыныстарды растауы.
6. Нәтижені экспорттау.
